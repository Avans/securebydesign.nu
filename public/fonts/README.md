# Lokale lettertypen

Fraunces (normaal 400/600/700, cursief 500), Hanken Grotesk (400/500/600/700) en JetBrains Mono (400/500).

Gedownload op 27 september 2026 uit de bestaande Google Fonts CSS-selectie. Alle aangeboden taal-subsets en unicode-ranges zijn behouden. WOFF2-bestanden worden via `/fonts/` vanaf dezelfde website geserveerd; de browser benadert Google niet.

`app/assets/css/fonts.css` bevat de bijbehorende font-face-regels met `font-display: swap`. `sources.json` bewaart de oorspronkelijke download-URLs. De drie `*-OFL.txt`-bestanden bevatten de SIL Open Font License en auteursrechtvermeldingen uit de officiële google/fonts-repository.
